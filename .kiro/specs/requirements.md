# 垂直農場排程系統 — 需求規格文件

> 版本：v1.0　日期：2026-09-21
> 範圍：Phase 1 PoC 雛型畫面，純前端、模擬資料、無後端。

---

## 系統概述

提供垂直農場現場人員一個簡單的排程輔助介面，涵蓋兩個核心功能：
1. **SC-01 訂單倒排排程**：輸入訂單交期，自動計算育苗與定植的啟動日。
2. **SC-04 今日派工看板**：依排程結果顯示當日行動清單，讓作業員知道該做什麼。

---

## 使用者故事與驗收條件

---

### US-01　訂單倒排排程

**身為** 場長，
**我想要** 輸入訂單品項、目標重量與交貨日期，
**以便** 系統自動算出育苗日與定植日，不再手工查表。

#### 驗收條件

| # | 條件 |
|---|------|
| AC-01-1 | 頁面提供表單，欄位包含：菜種（下拉選單）、預計採收重量（kg）、交貨日期（日期選擇器）。 |
| AC-01-2 | 按下「計算排程」後，系統根據各菜種的標準生長天數（模擬資料），以倒推方式計算「定植日」與「育苗日」。 |
| AC-01-3 | 計算結果顯示在表單下方，格式為：菜種、交貨日、定植日、育苗日、生長天數。 |
| AC-01-4 | 若交貨日期早於今日，顯示紅色警示「交期已過，請重新確認」，不執行計算。 |
| AC-01-5 | 頁面上同時以甘特條狀圖（純 CSS/HTML）呈現育苗期與生長期的時間區間。 |
| AC-01-6 | 所有菜種資料為模擬資料（hardcoded），不呼叫任何外部 API。 |

**模擬菜種資料（生長天數）**

> 業務規則：種子播種後第 8 天定植上架，上架後 2 週（14 天）出貨，所有菜種適用相同標準。

| 菜種 | 育苗天數 | 生長天數 |
|------|---------|---------|
| 奶油萵苣 | 8 | 14 |
| 蘿蔓生菜 | 8 | 14 |
| 芝麻葉 | 8 | 14 |
| 小白菜 | 8 | 14 |

---

### US-02　今日派工看板

**身為** 現場作業員，
**我想要** 開啟平板後直接看到今天要做哪些事、在哪個架位，
**以便** 不再依賴白板或口頭交辦，減少採錯層的疏失。

#### 驗收條件

| # | 條件 |
|---|------|
| AC-02-1 | 頁面顯示「今日（模擬日期）行動清單」，列出多筆派工任務。 |
| AC-02-2 | 每筆任務顯示：任務類型（播種／定植／採收）、架位編號（如 A 架 3 層 2 號板）、菜種名稱、數量。 |
| AC-02-3 | 任務依類型以不同色標區分：播種＝藍色、定植＝綠色、採收＝橘色。 |
| AC-02-4 | 作業員可點擊任務卡片上的「完成」按鈕，該任務標記為完成（視覺上灰色劃掉），狀態僅保存在頁面記憶體中，重新整理後恢復原始狀態。 |
| AC-02-5 | 頁面頂部顯示今日完成進度，格式為「已完成 X／Y 項」。 |
| AC-02-6 | 所有派工資料為模擬資料（hardcoded），不依賴後端或資料庫。 |

## 非功能需求

| 項目 | 說明 |
|------|------|
| 技術限制 | 純 HTML／CSS／JavaScript，不使用任何框架或外部函式庫 |
| 語言 | 介面全部使用繁體中文 |
| 響應式 | 須支援手機、平板與桌機三種裝置寬度 |
| 資料 | 全部使用 hardcoded 模擬資料，不接外部 API |
| 無需功能 | 登入、帳號管理、後端、資料庫、即時更新、通知推播 |
